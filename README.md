# AI Pest Finder

## Overview
AI Pest Finder is a Python-based project developed using Jupyter Notebook to explore dataset preparation, pest-related image processing, and pest classification workflows.

## Project Notebooks

- `01_dataset_setup_clean.ipynb` — Dataset setup and preparation.
- `02_fastapi_cleaned.ipynb` — FastAPI-related implementation.
- `03_non_pest_cleaned.ipynb` — Non-pest classification workflow.

## Technologies
- Python
- Jupyter Notebook
- FastAPI
- Machine Learning / Image Processing

## Getting Started

1. Clone or download this repository.
2. Install the dependencies required by the notebooks.
3. Open the notebooks in Jupyter Notebook.
4. Run the cells in the required order.

## Dataset
Use the dataset configured in the notebook. Dataset paths may need to be updated for your local computer.
